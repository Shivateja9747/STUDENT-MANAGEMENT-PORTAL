# 🎓 EduTrack Frontend - Student Attendance & Academic Performance Management System

React (Vite) frontend application built with **React Router v6**, **Axios**, **Lucide Icons**, and **Plain CSS Design Tokens**.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build
```

Please refer to the root `README.md` at `e:/Shiv/README.md` for full system documentation, role credentials, and API synchronization details.
